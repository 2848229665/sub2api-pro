# 新站产品决策与需求依据

这次重建优先解决“请求能否正确到达上游、调用为什么失败、费用如何产生、如何快速接入”，继续复用已有认证、分组、密钥、账单和调度实现。新站暂用名称“澄川 AI · Relay”，管理员仍可配置站名与品牌。

## 本次交付范围

- 默认中文首页：真实可达的控制台、密钥、模型与接入指引；复制本站 API 地址。
- 用户工作台：来自现有 API 的用量、费用、余额、近期请求；加载/失败/无数据状态。
- 账号保护：以初代兼容传输为基础，稳定账号设备身份、会话隔离与并发限制，允许有依据的协议转换。
- 管理端：沿用现有账号、分组、代理、监控、计费管理；修复保护开关和版本状态解释。
- 独立服务器部署：源码构建、健康检查、持久存储、日志、回滚说明。
- 验证：升级故障可复现、修复回归、前端构建和浏览器、服务器 API 验证；真实账号对照依赖可用凭据。

## 效果边界

“防降智”是用户原有功能名。本次可验证的是本地请求语义、传输兼容性、账号隔离和调用结果；不能由模板名称、HTTP 200 或 UI 开关推导模型质量保证。第三方平台的账号限制和能力规则仍由上游决定。
